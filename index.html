Step 01

Key Schedule

The 64-bit key from the top bar becomes sixteen 48-bit round keys. Every eighth bit is a parity bit, so PC-1 keeps only 56 bits. Those split into halves C and D, which rotate left by 1 or 2 each round. PC-2 then selects 48 of the 56 bits.

Step 02

Round Explorer

Enter one raw 64-bit block as 16 hex digits (no padding). Then move through the rounds. Each round computes Li = Ri−1 and Ri = Li−1 ⊕ f(Ri−1, Ki).

Step 03

Encrypt & Decrypt

Text becomes UTF-8 bytes. PKCS#7 pads it to a multiple of 8 bytes (an exact multiple gets a full extra block). Each block is encrypted on its own in ECB mode.

    Why ECB Leaks

    ECB encrypts every 8-byte block on its own with the same key. Equal plaintext blocks therefore give equal ciphertext blocks, so patterns in the data show through. Each colour below is one distinct ciphertext block.

    So what should be used instead?

    DES itself is broken. Its 56-bit key was brute-forced in less than a day in 1999. Real systems use AES with an authenticated mode such as GCM, which adds a random nonce so equal blocks look different, and which detects tampering. This site exists to show how block ciphers work inside.
